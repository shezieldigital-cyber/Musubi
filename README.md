# musubizzz — Musubi demo

This project recreates the requested mobile-first style with a different brand/content:
**musubizzz** and three Musubi products.

Requested displayed figures:
- Musubi 300 — price ₱300, displayed daily ₱60 + sign-in ₱5, 30 days
- Musubi 500 — price ₱500, displayed daily ₱135, 30 days
- Musubi 800 — price ₱800, displayed daily ₱210, 30 days

## Safety / product behavior
This is a **simulation/demo**, not a real investment or payment system. The displayed daily
figures are presented as user-provided example values and are not represented as guaranteed
profit or investment returns. "Select demo product" does not take payment or activate a real
financial contract.

## Run
1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3000.

admin@musubizzz.local
Admin123!
